# Apresentação do Projeto

Este projeto foi desenvolvido em linguagem Java durante as aulas de Programação Orientada a Objetos onde foi aprimorado técnicas de programação utilizado a Linguagem Java através do Spring Boot e também com o Eclipse IDLE para o desenvolvimento desta aplicação. 
Neste exemplo utiliza um sistema básico de um cadastro de clientes de um salão de beleza, aprendendo as principais técnicas sobre o certame, o último tópico foi sobre a Herança, o que é praticamente uma exclusividade desta linguagem.
