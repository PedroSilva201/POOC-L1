# Apresentação do Projeto

Este projeto foi desenvolvido em linguagem Java durante as aulas de Porgramação Orientada a Objetos onde foi aprimorados tecnicas de programação utilizado a Linguagem Java atraves do Spring Boot e tambem com o Eclipse IDLE para o desenvolvimento desta aplicação.
Neste exemplo utiliza uma sistema basico de um cadastro de clientes de um salão de beleza, aprendendo as principais tecnicas sobre o certame, o ultimo tópico foi sobre a Herança, o que é praticamente uma exclusividade desta linguagem.
